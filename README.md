## Сторонние библиотеки

В проекте используется библиотека nlohmann/json (файл `json.hpp`)
для работы с форматом JSON.

- Автор: Niels Lohmann
- Лицензия: MIT
- Репозиторий: https://github.com/nlohmann/json

Файл `json.hpp` является сторонней библиотекой и не относится
к авторскому коду данного проекта.
